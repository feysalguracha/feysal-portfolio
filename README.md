### 1. High-Traffic Node.js + Express + PostgreSQL API
**Problem**: API had 1.5-4s latency under 200 req/s load due to race conditions and N+1 queries.
**Solution**: 
- Replaced shared global cache with keyed Redis cache + TTL
- Rewrote sequential DB calls into single JOIN query 
- Implemented pg.Pool for connection management
**Result**: Reduced response time to <200ms, supports concurrent users.
